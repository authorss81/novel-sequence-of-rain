# Novel Bible

The bootstrap canon for *The Sequence of Rain* is organized here:

- `premise.md` — the central promise, canonical read/binding rule, opening crisis, and mystery.
- `world.md` — Veyra, the Ninefold Basin, institutions, history, and ordinary weather work.
- `characters.md` — protagonist arc, supporting motives, relationships, and antagonist responsibilities.
- `power-system.md` — Six Movements, branch spending, binding limits, advancement gates, and costs.
- `themes.md` — recurring questions, competing positions, motifs, and tests for each major choice.
- `terminology.md` — approved names and language rules for prose and outlines.

The series and ending constraints live in `outline/series.md` and `outline/ending.md`. The top-level concept uses “prediction” as public shorthand; the technical rule in `premise.md` and `power-system.md` is that only a witnessed, precise binding spends a branch. No chapter prose is part of this bootstrap.
